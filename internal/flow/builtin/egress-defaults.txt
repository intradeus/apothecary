# Sensible egress-allowlist defaults, offered (not enforced) per project.
#
# The egress gateway filters the DinD sandbox's inner daemon AND the
# devcontainer BUILD (image pulls, apt/npm/pip, plus apothecary's own injected
# harness + code-server tooling). A normal build needs most of these; a project
# that doesn't can drop the lines it doesn't use. These are read-only
# package/registry mirrors (low exfil value).
#
# Lines starting with # and blank lines are ignored. One host per line;
# `*.suffix` wildcards are honored by the gateway.
